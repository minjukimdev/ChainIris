# ChainIris

Monitors and visualizes blockchain data for cryptocurrency traders and analysts in a simple, customizable interface.

ChainIris is built to be simple and practical, focusing on doing one thing well.

**Why ChainIris?**

- Monitors and visualizes blockchain data
- for cryptocurrency traders and analysts
- in a simple, customizable interface

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ChainIris.git`
2. `cd ChainIris`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainIris is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
